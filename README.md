# Vorian scheduler portal (demo)

The screen a charter operator's scheduler would see in Vorian: the week on a timeline, Vorian's suggested changes with a reason for each, approve or keep current, and a sick call that Vorian re-plans around.

Try a schedule fills in a made-up weekly schedule as a spreadsheet table and runs Vorian on it. Every result on this page was computed ahead of time by Vorian's scheduler and legality checker, so the page needs no server; running your own schedule needs the live version.

Made-up data. Vorian suggests; the operator's scheduler approves every change and keeps operational control (14 CFR 135.77).
