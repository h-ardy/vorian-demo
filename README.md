# Vorian scheduler portal (demo)

Two tabs. Weekly schedule shows a charter operator's week as the scheduler built it, with any trip that breaks a rule flagged; Generate a random week swaps in a different made-up week. Vorian's review shows the same week on a timeline with Vorian's suggested fixes, a reason for each, approve or keep current, and a sick call that Vorian re-plans around.

When no legal crew is left for a trip, Vorian leaves it uncovered with the reason instead of breaking a rule, and the scheduler decides: subcharter it, call in a reserve or contract pilot, or ask the client to move the time.

Every result on this page was computed ahead of time by Vorian's scheduler and legality checker, so the page needs no server. Made-up data. Vorian suggests; the operator's scheduler approves every change and keeps operational control (14 CFR 135.77).
