# Vorian scheduler portal (demo)

The screen a charter operator's scheduler would see in Vorian: the week on a timeline, Vorian's suggested changes with a reason for each, approve or keep current, and a sick call that Vorian re-plans around.

Made-up operator and data. Every number on the page comes from Vorian's scheduler and legality checker, computed ahead of time, so the page needs no server. Vorian suggests; the operator's scheduler approves every change and keeps operational control (14 CFR 135.77).
